# GitHub upload checklist
1. Create a private repository: `complaint-management-portal`.
2. Extract this ZIP.
3. Open `complaint_portal_starter`.
4. Upload all contents of this folder to the repository root.
5. Verify `manage.py`, `requirements.txt`, `render.yaml`, `config/`, `apps/`, `templates/`, `static/`, and `docs/` are at root.
6. Never commit `.env`, database files, real customer data, phone numbers, addresses, or attachment URLs.
7. Commit, then use Render → New → Blueprint to deploy from the repo.
